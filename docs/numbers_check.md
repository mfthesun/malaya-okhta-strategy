# numbers_check — числа из внешних источников

Числа, которые нельзя пересчитать из данных репозитория (`scripts/check_numbers.py` проверяет только внутренние). Каждое — с источником и статусом. В слайды попадают только после сверки с первоисточником; пометка `[проверить]` — на слайд не брать.

| Число | Где используется | Источник | Статус |
|---|---|---|---|
| Плотность СПб ~3 900 чел/км² (для сравнения с 8 243 в v2) | docs/diagnostics.md, слайд 06 | Росстат (численность/площадь города) | `[проверить]` — в слайдах сравнение не используется |
| Доля пожилых выше городской | docs/diagnostics.md, разд. 3 | Бюллетень Петростата «Численность… возраст-пол» 01.01.2024 (PDF в kolomna-identity/sources_petrostat) | `[проверить]` — в слайдах не используется |
| Доля промзон в прибрежной полосе — нижняя оценка (слой OSM неполон) | docs/diagnostics.md, слайд 07 | собственные слои OSM | используется как «нижняя оценка», явная оговорка на слайде |
| Население СПб, районов, МО | ноутбуки 01, слайд 04 | Петростат/ВПН — пересчитывается, есть в check_numbers | подтверждено |
| Кейсы мирового опыта (гектары, годы, компании) | docs/world_cases.md, слайд 10 | ссылки в конце каждого раздела world_cases (проверены субагентами 02.11.2026, ≥2 источника на цифру) | подтверждено для слайда 10 (тезисы без деталей) |

## Демография: район vs МО

- Численность населения — по МО (ВПН-2010, оценки Петростата 01.01, ВПН-2020) — ряд в `data/raw/population_spb_mo_2010_2025.csv`.
- Возрастно-половой состав — **только по Красногвардейскому району** (`data/raw/age_sex_spb_districts_2024.csv`, бюллетень 01.01.2024); в слайдах всегда подписывается «Красногвардейский район», не «МО».
- Данных о маятниковой миграции и национальном составе по внутригородским МО в использованных источниках нет — соответствующие тезисы (дневной отток, приезжие/местные) подаются как качественная рамка команды без чисел.

## Версии границ и метод (обязательные пометки)

- v1 историческое ядро 1,80 км² ⊂ v2 МО Малая Охта 5,26 км² ⊂ v3 вся Охта 11,06 км²; v4 полуостров 10,55 км² (буфер 1 200 м от осей рек). Границы v2/v3 — OSM relations 1185381/1185383.
- Пешая доступность — **по сети** (`network_access_fallback.py`, прогон 03.11.2026); буферы по прямой не используются в презентации, упомянуты только как сравнение.
- Застройка/сервисы — OSM через `extract_okhta.py` (PBF Geofabrik 02.11.2026); счётчики фиксируются датой прогона.
