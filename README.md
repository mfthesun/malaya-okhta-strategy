# Малая Охта 2027–2035 — стратегия развития района

Командный проект по дисциплине «Формирование пространственного видения города» (ИТМО): стратегия развития
района **Малая Охта** (Красногвардейский район Санкт-Петербурга) на горизонте 2027–2035 и презентация к защите.

## Состав проекта

| раздел | статус |

| [docs/world_cases.md](docs/world_cases.md) — мировой опыт районных стратегий | в работе |
| [docs/data_catalog.md](docs/data_catalog.md) — каталог данных и источников | в работе |

## Территория

Приняты **несколько версий границ** (приём проекта «Коломна»): историческое ядро Малой Охты, МО Малая Охта
(официальная территория), охтинский полуостров с мысом, расширенная версия. Каждая включает предыдущую.

## Ключевые цифры (прогон 02.11.2026)

- Население МО Малая Охта: 45 946 (ВПН-2010) → 43 319 чел. (01.01.2025) — Петростат/ВПН.
- Все числа документа воспроизводимы ноутбуками `notebooks/` и проверяются `scripts/check_numbers.py`.

## Как запускать

```bash
pip install -r requirements.txt
python3 scripts/process.py && python3 scripts/validate.py
python3 scripts/check_numbers.py
jupyter lab notebooks/
```
