# Малая Охта 2027–2035 — стратегия развития района

Командный проект по дисциплине «Формирование пространственного видения города» (ИТМО): стратегия развития
района **Малая Охта** (Красногвардейский район Санкт-Петербурга) на горизонте 2027–2035 и презентация к защите.

## Территория

Приняты **несколько версий границ** (приём проекта «Коломна»): историческое ядро Малой Охты, МО Малая Охта
(официальная территория), охтинский полуостров с мысом, расширенная версия. Каждая включает предыдущую.

## Ключевые выводы (прогон 02.11.2026, check_numbers 24/24)

- Население МО Малая Охта: 45 946 (ВПН-2010) → 43 319 чел. (01.01.2025), **−5,7 %** — единственное убывающее МО среди охтинских (Большая Охта: +6,7 %).
- Берег оторван: в 300-метровой полосе Невы и Охты жилая застройка — **5 %**; общественных пространств у воды нет; Ниеншанц (Охта 1) — огороженный раскоп.
- Индустриальная морфология: **71 %** жилфонда с известным годом — 1946–1991; до 1917 — 4,8 %.
- Сервисные «дыры»: школы 500 м — 77 % жилых зданий, детсады 300 м — 64 % (буферы по прямой).
- Ресурсы: 60 ОКН (17 федеральных), 2 станции метро, 43 % территории — зелень.
